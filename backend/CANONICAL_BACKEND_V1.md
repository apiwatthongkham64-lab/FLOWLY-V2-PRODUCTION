# FLOWLY Canonical Backend V1

This folder is the single source of truth for the backend.

Included:
- PostgreSQL pool
- bcrypt password hashing
- HTTP-only session cookie
- Register/Login/Logout/Me
- Customers CRUD
- Customer booking history
- Business-scoped authorization
- E2E smoke test

The smoke test requires a real PostgreSQL/API environment; it has not been claimed as runtime-passed in this workspace.
